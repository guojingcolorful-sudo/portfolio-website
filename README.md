# Portfolio Website

个人作品集网站（React + Vite）：展示个人项目与作品的多屏滚动作品集站点。

## 快速开始

```bash
npm install
npm run dev       # 本地开发
npm run build     # 生产构建
npm run preview   # 预览构建产物
```

## 技术栈

- React + Vite
- 响应式布局（全视口自适应，窄屏回退普通流）

## 结构

```
src/
├── data/      站点内容（作品、项目信息）
├── components/ 页面组件
└── App.jsx     页面骨架
```

## 隐私

站点内容均为本人作品的公开展示；请勿提交包含个人敏感信息的文件（如未发布的截图、证件、合同等）。
